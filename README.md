# Evently – Event Management Website

A modern, responsive event discovery and management website built using React.js, Vite, Tailwind CSS and JavaScript.

## 🌟 Project Overview

Evently helps users discover upcoming events, explore event categories, view detailed event information and register for their preferred events through a clean and interactive interface.

## ✨ Features

- Modern and responsive homepage.
- Featured and upcoming events.
- Event search functionality.
- Category-based filtering.
- Event details pages.
- Registration form with JavaScript validation.
- Local Storage-based registration management.
- Event countdown timer.
- Light and dark mode.
- Smooth animations and transitions.
- Responsive mobile, tablet and desktop layouts.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- React.js
- Vite
- Tailwind CSS
- Framer Motion
- Lucide React
- React Router

## 💻 Installation and Setup

Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

Open the project:

```bash
cd Evently
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Create a production build:

```bash
npm run build
```
